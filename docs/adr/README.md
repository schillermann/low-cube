## Suggested ADR Format

When recording new architectural decisions, create a file named `XXXX-topic-title.md` using the following structure:

1. **Title & Metadata**: Status (Draft / Accepted / Superceded), Date, Deciders.
2. **Context & Problem Statement**: What technical challenge needs to be addressed?
3. **Decision Drivers**: Key constraints, hardware limits, performance targets.
4. **Considered Options**: Alternative approaches or technologies evaluated.
5. **Evaluation & Comparison**: Pros, cons, and trade-offs.
6. **Decision Outcome**: Chosen path and concrete rationale.
7. **Consequences & Architectural Rules**: Impact on development, risks, and implementation guidelines.
